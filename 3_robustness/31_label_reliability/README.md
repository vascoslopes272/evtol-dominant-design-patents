# 31_label_reliability

`src/perturb.py` replaces a share of the coded values by random errors, `src/core.py` recomputes the eight results of the paper from the perturbed table, and `src/31B_run_replicas.py` repeats this 1 000 times. The results are in `eVTOL_dataset/07_results/71_label_reliability`.
