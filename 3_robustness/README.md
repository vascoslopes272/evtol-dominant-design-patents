# 3_robustness

Checks of how far the results depend on the choices of the analysis.

| Step | Question |
|---|---|
| `31_label_reliability` | How much do the results change if a share of the author's labels were wrong? |
| `32_weight_sensitivity` | How much does the dominant-design test change with the weights of its third condition? |
| `33_query_completeness` | Does the query find the aircraft that are known to exist? (code in step 11) |

The results are in `eVTOL_dataset/07_results`.
