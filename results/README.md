# results

The figures (PDF and PNG) and CSV files written by the notebooks of `2_analysis`, one folder per step. Run `2_analysis/20_run_all.sh` to produce them.

All numbers and figures are computed from the public dataset `eVTOL_dataset` (621 designs, 619 with an architecture). The dataset is expected next to this repository, or at the path in the variable `EVTOL_DATASET`.
