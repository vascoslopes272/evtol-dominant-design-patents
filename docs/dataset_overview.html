03_patents/The 1 639 patent families: what the text says and the author's labels. This folder holds what the wizard (the HTML tool used to label) takes in and what it produces. Files 30 and 31 are machine output, not labels, and nothing in them was reviewed or checked. File 32 is the labels. - **File 30** holds the suggestions the wizard shows when a batch is loaded: SigLIP on the figures, SBERT on the text and fields taken from the PatSeer record, each with a confidence and a flag that says whether it needs review. They were only an aid to label faster. - **File 31** is a different thing: what a script read in the text of each patent about the aircraft (name, powertrain, take-off, UAV), which is what tells whether the patent describes an electric aircraft inside the domain. - **File 32 is the real file of the dataset.** It holds every label the author gave, in the long format of the wizard (one row per field). The easiest way to see these labels is to open file 32 in the wizard HTML (wizard/11H_master_wizard.html in the GitHub repository), which shows each patent with its figures and labels. The wizard has two file inputs, the batch to review (file 30) and an optional earlier export to resume from (file 32). Files 33, 41, 42 and 43 hold the same labels as tables, so they can be read without opening the wizard. They add no labels of their own. In file 32 the sections META and T1 are patent level (they give file 33), T2 is figure level (file 41) and G1, M1, M2, M3 are aircraft level (file 42). The tables have one row per patent, figure or aircraft, the rejected patents are left out of file 42, and some columns are calculated (duplicate of, number of figures, final electric). Why file 33 is needed: it is the only table with one row for each of the 1 639 patent families. File 42 lists only the 1 108 patents that have an approved aircraft, so the 531 patents without one, and the reason, appear as a table only in file 33.

# 03_patents

This folder holds what the wizard (the HTML tool used to label) takes in and what it produces. Files 30 and 31 are machine output, not labels, and nothing in them was reviewed or checked. File 32 is the labels.

- **File 30** holds the suggestions the wizard shows when a batch is loaded: SigLIP on the figures, SBERT on the text and fields taken from the PatSeer record, each with a confidence and a flag that says whether it needs review. They were only an aid to label faster.
- **File 31** is a different thing: what a script read in the text of each patent about the aircraft (name, powertrain, take-off, UAV), which is what tells whether the patent describes an electric aircraft inside the domain.
- **File 32 is the real file of the dataset.** It holds every label the author gave, in the long format of the wizard (one row per field). The easiest way to see these labels is to open file 32 in the wizard HTML (`wizard/11H_master_wizard.html` in the GitHub repository), which shows each patent with its figures and labels. The wizard has two file inputs, the batch to review (file 30) and an optional earlier export to resume from (file 32).

Files 33, 41, 42 and 43 hold the same labels as tables, so they can be read without opening the wizard. They add no labels of their own. In file 32 the sections `META` and `T1` are patent level (they give file 33), `T2` is figure level (file 41) and `G1`, `M1`, `M2`, `M3` are aircraft level (file 42). The tables have one row per patent, figure or aircraft, the rejected patents are left out of file 42, and some columns are calculated (duplicate of, number of figures, final electric).

Why file 33 is needed: it is the only table with one row for each of the 1 639 patent families. File 42 lists only the 1 108 patents that have an approved ai
04_aircraft/The aircraft, figures, designs and their technology readiness levels (TRL). Files 41 and 42 are the labels of file 32 as tables (figure level and aircraft level). File 43 gives the architecture class of each aircraft from the figure and from the text. File 44 adds the technology readiness levels (TRL) and is built from the evtol.news directory in folder 06. File 45 is the list of the 621 designs of the analysis: the labels of file 32 (through file 42) plus the TRL of file 44. The suggestions the wizard showed are in 03_patents, file 30.
